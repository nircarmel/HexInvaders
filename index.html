How to Play

Goal — Two Game Modes

  • Invade Game - First to move any unit onto the enemy base wins.
  • Plant Game - First to move a flag unit onto the enemy base wins.

Core Rules

  • Board - hexagonal grid, two players: Blue (base on left) and Red (base on right).
  • Budget - each player starts with 0 units and a budget of 100 credits to deploy new units.
  • Turn-Based: One action per turn: deploy, move, attack, barricade, or skip.
  • Combat Resolution: When a unit moves into a tile occupied by an enemy unit, combat ensues. Higher Power wins; ties favor the attacker (mover). The loser is destroyed. The winner also loses 1 Power point after the battle. If a unit's Power is reduced to 0, it dies.

Units

  • Combat units: Power 1–5, Speed 1–5, cost = power × speed (1 to 25 credits).
  • Flag units: Power always 0, Speed 1–5, cost = 5 × speed (5 to 25 credits).
  • Observation units: Weak stationary observation unit, Power = 0, Speed = 0. Deployed behind a newly created barricade and offers long distance visibility over a barricade.

Actions

  • ⚔️ Deploy Combat Unit: Use credits to create a new combat unit at your home base.
    (Action: Left-click an empty tile in your base → Choose Speed and Power → Deploy)
  • 🚩 Deploy Flag Unit: Use credits to create a flag unit at your home base.
    (Action: Right-click an empty tile in your base → Choose Speed → Deploy)
  • ➡️ Move Unit: Move your own unit into a vacant tile.
    (Action: Left-click a unit → Click vacant destination)
  • 💥 Attack Unit: Move your own unit into a tile occupied by an enemy unit.
    (Action: Left-click a unit → Click enemy destination)
  • 🧱 Build Barricade: A combat unit converts itself into a barricade: a vertical block. Its length scales with the converting unit's Power. Creating a barricade intrinsically deploys a stationary observation unit just behind it, penetrating the enemy's fog-of-war while blocking theirs.
    (Action: Right-click a unit → Scroll mouse-wheel to rotate)

User Interface Tips

  • Movement Range Overlay: Toggle an overlay that highlights the tiles each army can reach.
    Note: When an enemy unit's speed is unknown (too far away), its range slowly pulses to show possible reach.
  • Hover Mechanics: Hover over any unit to see three ranges at once:
    (a) Moving range (inner blue/red outline): tiles it can reach in one turn
    (b) Inspecting range (middle): see enemy power and speed
    (c) Spotting range (outer): see enemy locations, but not their details
